# Experimentos anteriores

legacy_experiments_2026-10-26.tar.gz conserva los resultados históricos, checkpoints,
código y documentación de las escaleras de 10 chunks y de la prueba descartada
con todos los chunks. No es necesario extraerlo para la ejecución actual.

El contenido se verificó antes de retirar los originales. cleanup_manifest.json
lista cada archivo archivado y las pruebas redundantes eliminadas. Para reproducir
los experimentos antiguos, extraer en una carpeta independiente, conservando la
estructura original y ajustando las rutas a los datos.
